# Decay3D

A 3D zombie shooter prototype developed in Unity using C#.

## Overview

Decay3D is an ongoing solo development project focused on
third-person movement, combat, enemy behavior, and gameplay
systems.

The project began as part of my game development training
and has since been expanded through personal modifications
to gameplay mechanics, scripts, visuals, and environments.

## Features

- Player movement and combat
- Enemy AI and navigation using Unity NavMesh
- Enemy animations and gameplay interactions
- Level design and environmental setup
- Audio integration
- Customized models, materials, lighting, and UI

## My Contributions

- Developed and customized gameplay mechanics and C# scripts
- Integrated player and enemy systems
- Modified enemy behavior and animations
- Customized environments, materials, and lighting
- Debugged AI behavior, animation synchronization, and
  navigation issues
- Iteratively tested and refined gameplay systems

## Technologies

- Unity
- C#
- Unity NavMesh
- Animator
